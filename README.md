W# GPA Calculator

A full-screen, mobile-friendly GPA Calculator built using HTML, CSS, and JavaScript.  
This project helps students calculate their GPA easily using the standard weighted average formula.  
The application features a clean blue–white professional UI with clear instructions for use.

---

Live at : https://pandeyujjwal975.github.io/GPA-Calculator/

## Features

- Full-screen responsive design  
- Clean and professional blue–white UI  
- Easy to use for students  
- Supports multiple subjects  
- Accurate GPA calculation using grade points and credits  
- Works smoothly on mobile and desktop devices  
- No external libraries or frameworks  

---

## How to Use

1. Enter the **Grade Point** for a subject.  
2. Enter the **Credit value** for that subject.  
3. Click **Add Subject** to add more subjects.  
4. After entering all subjects, click **Calculate GPA**.  
5. The final GPA will be displayed instantly.

---

## How GPA Is Calculated

The GPA is calculated using the standard weighted average formula:

## Steps used in calculation:
- Each subject’s grade point is multiplied by its credit value  
- All results are added together  
- The total is divided by the sum of credits
